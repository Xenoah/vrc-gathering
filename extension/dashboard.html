    収集と保存

    公式サイトのログイン状態を利用します。初回は停止状態です。

    Googleスプレッドシート同期

    下のセットアップ手順でGASを用意し、URLと同期キーを登録してください。有効にすると全アカウントのフレンド・ワールド・変更履歴・巡回記録を送受信します。

    収集後・画面表示時・約5分ごとに同期します。通信失敗時は端末の記録を表示し、再試行します。別端末でも同じURLと同期キーを設定できます。

    はじめてのGASセットアップ

    スプレッドシートの作成から同期開始まで、次の6ステップで設定できます。GAS（Google Apps Script）は、ご自身のGoogleアカウントで動作します。

    1. スプレッドシートを新規作成

      Googleスプレッドシートを作成 ↗し、共有設定は非公開のままにします。URLの /spreadsheets/d/ と次の / の間がスプレッドシートIDです。

    2. Apps Scriptにコードを配置

      シートの「拡張機能 → Apps Script」を開き、Code.gs の内容を置き換えます。スクリプトファイル Protocol も追加し、Protocol.gs の内容を貼り付けます。2つとも必要です。

      Code.gs保存・送受信の処理ファイルを保存
      Protocol.gs記録形式の検証ファイルを保存

      コードは拡張に同梱しています。コピーできない場合は「ファイルを保存」で取得し、テキストエディターから貼り付けてください。

    3. 3つのスクリプトプロパティを設定

      Apps Scriptの「プロジェクトの設定 → スクリプトプロパティ」で追加します。

      SPREADSHEET_ID
      手順1で控えたスプレッドシートID。
      SYNC_TOKEN
      パスワードマネージャー等で生成したランダムな32〜256文字の英数字・ハイフン・アンダースコア。後で拡張にも同じ値を設定します。
      RETENTION_DAYS
      クラウドの保存日数。1〜365。未設定の場合は30日です。

      同期キーを知る人は保存した全アカウントの記録を読み書きできます。キーは他人に共有せず、VRChatのパスワードや認証トークンは入力しないでください。

    4. setupを一度実行

      エディター上部で setup 関数を選んで実行し、Googleのアクセス許可を確認します。VRCRecords シートと、保存期間を過ぎた記録を日次で整理するトリガーが作成されます。

    5. ウェブアプリとしてデプロイ

      「デプロイ → 新しいデプロイ → ウェブアプリ」で、「次のユーザーとして実行」は 自分、「アクセスできるユーザー」は 全員 を選びます。GAS側で同期キーを照合するため、スプレッドシート自体の公開は不要です。

      デプロイ後、末尾が /exec のURLをコピーします。/dev は使いません。組織の設定で「全員」を選べない場合は、管理者が認める公開方法を確認してください。

    6. この拡張にURLと同期キーを登録

      同期設定にGASのURLと SYNC_TOKEN と同じキーを入力し、「記録をGoogleスプレッドシートと同期する」をオンにして保存します。Googleへの追加接続権限を許可し、上部に「同期完了」が表示されることを確認してください。

      別端末でも同じURLとキーを登録できます。閲覧だけならVRChatへのログインや収集開始は不要です。

    うまく同期できないとき・GASを更新するとき
    同期キーが一致しません
    GASの SYNC_TOKEN と、拡張に入力したキーを確認します。保存済みのキーは、入力欄を空欄のまま保存すると維持されます。
    GASがJSONを返しません
    URLが /exec であることと、公開範囲が「全員」であることを確認します。URLをブラウザで開いたときの POST_REQUIRED は正常です。
    コードを更新したのに反映されません
    Apps Scriptの「デプロイを管理 → 編集 → 新バージョン」で既存のデプロイを更新します。コードの保存だけでは公開済みの内容は更新されません。
    GASの実行設定を確認したい
    V8ランタイムを使います。必要なら「appsscript.json マニフェスト ファイルをエディタで表示する」を有効にし、同梱のappsscript.jsonを保存して参考にしてください。

    端末内の記録を削除してもシートの記録は残り、同期を再開すると戻ります。クラウドと端末の保存日数は別設定です。

    保存される情報

    フレンドID、表示名、接続状態、ステータス・メッセージ、プラットフォーム、公開されたワールドID・名前・インスタンスID・種類・地域、観測日時と変更履歴。ワールドの作者名・定員もキャッシュします。

    PC内の拡張専用データベースに保存。同期を有効にした場合は指定のGoogleスプレッドシートにも保存します。VRChatの認証情報は同期しません。インスタンスIDに作成者ID等が含まれる場合があります。

    記録をすべて削除

    この端末の全アカウントの記録を削除し、収集・同期を停止します。スプレッドシートの記録は残ります。同期を再開すると再取得されます。

    Windowsで継続して使う

    1. 同じChromeプロファイルでログイン

      vrchat.comのログインと2段階認証を完了。パスワード・認証トークンをこの拡張に入力する必要はありません。

    2. 連絡先を保存して収集を開始

      収集設定にAPI識別用の連絡先を入力。拡張のアイコンから、いつでもこの画面を開けます。

    3. Chromeのバックグラウンド実行を有効に

      Chrome「設定 → システム → Google Chromeを閉じた際にバックグラウンドアプリの処理を続行する」を有効にします。Windowsログオン時の起動は同梱のwindows/Install-Startup.ps1でも設定できます。

    4. 履歴は定期的にエクスポート

      拡張の削除・プロファイル消去で記録も消えます。JSONは全履歴の保存用、CSVは一覧・差分の分析用です。JSONファイルの手動再インポートは未対応です。GAS同期では別端末の記録を取り込めます。

    Googleスプレッドシートと同期する

    GASの作成・公開・接続設定を、拡張内のガイドで進められます。必要なコードも同梱しています。

    収集が止まる条件

    Chromeの完全終了、Windowsのサインアウト／スリープ、ネット切断、認証切れ、サイト権限の未許可。Windowsのログオン前には動きません。

    公開範囲をそのまま扱う

    APIが所在を非公開にしている場合は「非公開」。非公開の居場所の推測、非フレンドの追跡、同席者一覧の収集は行いません。

    大量のフレンドがいる場合

    1巡回でオンライン最大2,000件、オフライン名簿最大500件を取得し、続きは次回へ。ワールド名は最大5件ずつ補完します。ページ取得中の状態変化で重複や抜けが生じる場合があり、IDで重複排除します。

    エラー時の動作

    401／403は停止。429／通信失敗は待機し、Retry-Afterと指数バックオフを適用。停止・再開やデータ削除をしても待機時間は解除しません。
